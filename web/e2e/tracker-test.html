Tracker test page

On load this page fires the Searchable GET beacon. Spoof the User-Agent in DevTools → Command Menu → “Show Network conditions”, then reload.

  1. Replace YOUR_TRACKING_ID below with a real site ID from the dashboard.
  2. From web/, serve over HTTP (not file://):
    npx serve . then open http://localhost:3000/e2e/tracker-test.html
  3. Spoof UA (e.g. GPTBot) and reload. Check the dashboard for the event.

Example GPTBot UA:
Mozilla/5.0 (compatible; GPTBot/1.0; +https://openai.com/gptbot)
